📦 Standalone app / APK

This launcher is the standalone app. Everything below turns it into an offline file or an Android APK.

1 — Install as app (no store, 10 sec)

Android Chrome: menu ⋮ → Add to Home screen → launcher opens fullscreen like a native app. iOS Safari: Share → Add to Home Screen. Your engagements stay on-device.
1) Open this page in Chrome (Android) → 2) ⋮ menu → Add to Home screen / Install app → 3) Launch “BugHunter” from home screen → 4) It runs fullscreen. This archive does not include a standalone service worker, so offline caching is not enabled.
Service worker: checking…

2 — Download standalone HTML (truly offline)

Single .html file with launcher + all skills + 15 commands + reports inlined (~3.5 MB). Double-click to run, no server. Share via USB/Bluetooth.

3 — Wrap into APK (PWABuilder, free, no code)

1) Copy app URL → 2) go to pwabuilder.com → 3) paste URL → Package for Android → download .apk / .aab → sideload to phone. Works because this page ships a web manifest + icons.
PWABuilder needs a public manifest + service worker + icons. Inside Perchance the platform owns the top-level SW, so for store/APK packaging host the FULL offline export (it bundles sw.js + manifest + icons) on GitHub Pages / Netlify / any HTTPS host, then run PWABuilder on that URL.

4 — Full repo ZIP + desktop CLI

git clone https://github.com/elementalsouls/Claude-BugHunter.git
cd Claude-BugHunter
bash scripts/install.sh        # macOS/Linux  (Windows: pwsh ./scripts/install.ps1)
pip install -e .               # cbh CLI
cbh recon example.com
cbh classify "https://example.com/reset?token=abc"
cbh triage finding.md
cbh report finding.md

5 — Android Termux (real cbh on phone, no APK needed)

pkg update && pkg install -y python git
git clone https://github.com/elementalsouls/Claude-BugHunter.git
cd Claude-BugHunter
bash scripts/install.sh
python scripts/cbh.py recon example.com
